Сюда можно положить .docx с нормальными UTF-8 именами файлов — при сборке они имеют приоритет над _articles_import.

Сборка: из корня проекта
  python scripts/build_blog_from_docx.py

Шаблон в Word: блоки «Описание страницы:», «Главный заголовок статьи:» (или «Главный заголовок:») — как в исходном архиве.
