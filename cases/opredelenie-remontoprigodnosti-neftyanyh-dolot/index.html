01 / Задача

Что нужно было решить

Нефтесервисная компания после каждого подъёма долота из скважины проводила ручной осмотр: опытный инженер оценивал степень износа шарошек, зубьев и корпуса и принимал решение — отправить на ремонт или списать.

Проблема: дефицит экспертов, субъективность оценки, время осмотра 20–40 минут при срочных операциях. Задача: автоматизировать оценку, стандартизировать критерии, ускорить процесс.

02 / Решение

Что мы сделали

Разработали систему фотофиксации долота (стенд с 3 камерами под разными углами) и модель классификации по 4 классам состояния согласно стандарту IADC.

  • Автоматический фотостенд — 3 ракурса за 30 секунд
  • Сегментация шарошек, зубьев, подшипников, форсунок
  • Классификация по IADC: A (новое) / B (лёгкий износ) / C (ремонт) / D (списание)
  • Отчёт с визуализацией дефектов и рекомендацией
  • История осмотров с трекингом каждого долота по серийному номеру
03 / Результаты

Что получил клиент

Время оценки одного долота сократилось с 20–40 минут до 5–7 минут. Стандартизация критериев исключила субъективные расхождения между экспертами.

  • В 3 раза быстрее оценка состояния
  • Точность классификации 93% (совпадение с решением эксперта)
  • Снижение стоимости необоснованных списаний на 22%
  • База данных осмотров для предиктивного обслуживания
04 / Технологии

Что использовали

Трёхкамерный фотостенд с управляемой подсветкой, Mask R-CNN для сегментации компонентов долота, EfficientNet-B4 для итоговой классификации, веб-интерфейс на FastAPI + React.
