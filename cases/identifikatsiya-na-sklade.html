01 / Задача

Что нужно было решить

Дорожная служба проводила регулярные объезды трасс для инвентаризации и проверки состояния дорожных знаков. Процесс был полностью ручным: видеозапись с видеорегистратора просматривалась оператором, знаки фиксировались вручную.

Задача: автоматизировать распознавание знаков из видео GoPro, определять их класс по ГОСТ Р 52290, привязывать к GPS-координатам и формировать отчёт — без интернета, на ноутбуке в машине.

02 / Решение

Что мы сделали

Разработали десктоп-приложение на Python + PyQt6 с встроенной моделью детекции и классификатором знаков по ГОСТ.

  • Детекция знаков на каждом кадре видео в реальном времени
  • Классификация по категориям ГОСТ Р 52290 (предупреждающие, запрещающие, информационные и т.д.)
  • GPS-привязка из NMEA-лога GoPro к каждому зафиксированному знаку
  • Экспорт в CSV и интерактивную карту в формате HTML
  • Полностью оффлайн — работает без интернета на обычном ноутбуке
03 / Результаты

Что получил клиент

Время инвентаризации 100 км дороги сократилось с 3 рабочих дней до 4 часов. Ручной просмотр видео полностью исключён.

  • Recall 94% на тестовой выборке из реальных дорог
  • Latency 12 мс на кадр (CPU-режим, без GPU)
  • Сокращение трудозатрат на инвентаризацию в 6 раз
  • Автоматический отчёт с картой вместо ручных таблиц
04 / Технологии

Что использовали

YOLOv8n для детекции (оптимизирован под CPU), EfficientNet-B0 для классификации, PyQt6 для интерфейса, OpenCV для обработки видео, Folium для генерации карты. Сборка в exe через PyInstaller.
